Bring a finished track. The page cuts it into bars and records when each part plays during a run: SSX 3's music director follows that instead of playing the file straight through. In short: load a track, ctrl-drag the bars that belong to each state of a run, then press Sample run to hear it as a ride.

  • side material — heard only at high intensity
  • course zone — jumped into and back out of by events
  • finish — played once when the run ends

Each marker sits where its event fires: the event on top, what it does underneath. Press one while the preview plays.

Course triggers

The course fires event N when the rider hits a music trigger and N+1 on leaving; the song jumps to that section and returns to the bar it left.

    Donor song

    A shipped song whose map you inherit. It fixes the grid — one slice is one bar of yours — and the events your song has to answer, so the job is filling its slots rather than writing a map.

      What the rider hears

      The game never plays your file straight through. It plays the bars you marked, in the state the run is in.

      What each section is

      side material
      The top rung of the value ladder: the game climbs a 0-127 value over 13-20 s and resets it on impacts, and bars marked here are only reachable above 100. They play a third of the time at most, so the track has to survive without them: drums, bass, a riff rather than the hook. Measured: the ramp and its resets are in the engine code. Which rider events cause a reset is inferred, not measured.
      course trigger
      The course fires event N on entering one of its music triggers and N+1 on leaving; the song stores the bar it was on and returns to it. Same tempo and key, a different instrument or register, four to sixteen bars — a variation, so a switch in and out does not sound like a mistake. Measured: the N / N+1 behaviour and the store-return actions. What the game counts as a trigger is not measured, and this page will not guess at it.
      finish
      Event 10 at the line: the ending bars play once and the song stops. Measured, both in the map and in a race trace.

      Moments

      What a song can answer, and what is still unmeasured. A moment with no measured signal cannot be cued — see docs/moments.md.

      start
      event 0 — measured. A cue here is a pickup into the groove.
      flow, low value
      value 0-50 — measured. The thin rung of the ladder.
      flow, high value
      value 100-127 — measured. The full rung.
      impact
      a value reset, strength class 0.25 / 0.65 — in the code; which rider events cause it is inferred. A cue here is a hit that re-lands the groove.
      airborne
      no signal measured yet. Nothing can be cued on it until a trace says what fires.
      finish
      event 10 — measured. A stab and a tail.
